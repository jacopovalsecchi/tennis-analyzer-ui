# Tennis Analyzer UI — feature source

TypeScript modules for the app. The React Native project, dependencies, and native iOS/Android projects stay at the repository root.

| Folder | Purpose |
| --- | --- |
| `screens` | Profile, video upload, and results (strokes). |
| `components` | Reusable UI pieces shared across screens. |
| `navigation` | Stack and tab navigator setup. |
| `services` | API client for the Node backend, and video upload. |
| `hooks` | Custom hooks. |
| `types` | Profile, stroke data, and video upload status. |
| `utils` | Small shared helpers. |
| `assets` | Images, fonts, and other static files. |
